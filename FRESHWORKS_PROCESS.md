# Freshservice Issue Tracking Process

## Purpose

Freshservice was used to manage and track cybersecurity tasks throughout the project. It helped organize issues, assign priorities, record progress, and document completed work.

## Issue Tracking Workflow

The following workflow was followed for each issue:

1. Create a new ticket.
2. Add a clear title and description.
3. Assign a priority level.
4. Set the impact and urgency.
5. Assign the ticket to the appropriate group.
6. Work on the task.
7. Add a resolution note after completion.
8. Change the ticket status to Resolved or Closed.

## Benefits of Freshservice

- Organizes project tasks
- Tracks issue progress
- Records resolution details
- Improves teamwork and communication

## Integration with GitHub

Each development task was implemented in GitHub using feature branches and pull requests. Freshservice was used to record and manage the corresponding issues until they were completed.
